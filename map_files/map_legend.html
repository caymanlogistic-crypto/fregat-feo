Условные обозначения карты ФРЕГАТ

Справочник по принятой обновлённой версии карты. Для основных элементов показан крупный пример и рядом реальный рабочий размер 1:1.

Боевые размеры: заявка 50×40 px; склад 58×32 px; отдельный маркер утилизатора 74×30 px.

Как читать маркер заявки

  • Верхняя планка — утилизатор назначения.
  • Слева — сокращённое обозначение утилизатора.
  • Справа — номер рейса в формате #34; до включения в рейс номера нет.
  • Обводка, внутренняя линия и хвост — логистический статус.
  • До включения в рейс контур всегда чёрный.
  • Фон корпуса — диапазон массы.
  • Число в корпусе — общий вес в килограммах.
  • ADR — опасный груз по настройке утилизатора.

Логистический статус — цвет обводки

Масса — цвет корпуса

Утилизатор — цвет верхней планки

Цвета утилизаторов управляются из админки. В маркере заявки используется короткое обозначение.

ADR — опасный груз

увеличено ×5
боевой размер 1:1

Жёлтая плашка ADR появляется только при значении «Опасный груз = Да» у соответствующего утилизатора.

Выделенная заявка

увеличено ×4
боевой размер 1:1

Выделенная заявка получает синюю обводку, светлый фон и яркое синее свечение.

Столбик заявок в одной точке

Крупный пример
Боевой размер 1:1

Маркеры стоят строго по одной вертикали. У каждого маркера показан собственный хвост-указатель. Для ADR оставлено дополнительное пространство, чтобы плашка не конфликтовала с соседним знаком.

Склад

Обычный склад
увеличено ×5
боевой 1:1

Слева сверху — количество заявок, справа — суммарный вес, ниже — «СКЛАД».

Выбранный склад
увеличено ×5
боевой 1:1

Выбранный склад отображается зелёным.

Отдельный маркер утилизатора — НЭК

увеличено ×4
боевой размер 1:1

Боевой размер 74×30 px. Для НЭК используется основной цвет #8E24AA и тёмный контур #4A005F.
